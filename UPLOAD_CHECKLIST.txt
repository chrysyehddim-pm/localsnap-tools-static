- package.json

部署建議：
1. 如果用 GitHub Pages，Settings → Pages → Deploy from branch → main / root。
2. 如果用 Vercel，Framework Preset 選 Other，Build Command 留空。
3. 打開網站後，用瀏覽器 DevTools → Network 確認處理檔案時沒有 upload request。
